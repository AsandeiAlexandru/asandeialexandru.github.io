# Alexandru Asandei — Personal Portfolio

> Live Website: [https://asandeialexandru.github.io](https://asandeialexandru.github.io)

Personal developer portfolio and technical showcase for **Alexandru Asandei**, Computer Science student at the Technical University of Cluj-Napoca (UTCN) and Software Engineer.

## 🚀 Key Highlights & Projects Featured

- **[PhoneAsPeri](https://github.com/AsandeiAlexandru/PhoneAsPeri)**: Modular Hardware Remote Control System (`C++`, `Win32 API`, `Winsock2 UDP`, `Flutter`). Real-time communication with <10ms response latency and <5MB RAM footprint.
- **[LDD_FRS](https://github.com/TartaTudorAndrei/LDD_FRS)**: Full-Stack AI Football Analytics Platform (`Java 21`, `Spring Boot`, `Python FastAPI`, `GCP Cloud Run`, `Neon PostgreSQL`, `React`). Built during "U" Hackathon.
- **[Rentz Multiplayer Game](https://github.com/AsandeiAlexandru/LabProject_RENTZ_game)**: Object-Oriented tournament game engine and TCP socket client-server networking layer in Java & PostgreSQL.
- **[Erudit](https://github.com/aniteicristi/erudit)**: Gamified STEM learning mobile app developed in the 6-month DPIT (Descoperă-ți pasiunea în IT) mentorship program (`Flutter`, `C++`).
