Systems & Mobile

PhoneAsPeri

Modular Hardware Remote Control System

Engineered a distributed real-time remote control ecosystem connecting a cross-platform Flutter mobile client to a native C++ Windows daemon over local Wi-Fi with sub-10ms response latency and a <5 MB RAM footprint.

  • Zero-allocation UDP reception hot path: High throughput socket architecture with token-based boundary discard.
  • Hardware Event Emulation: Utilized native Win32 SendInput API for cursor movement, wheel scroll, and continuous gaming inputs (WASD).
  • Flutter Multi-Touch Studio: 64-key virtual keyboard, 8-directional analog joystick, and a Gyroscope "Air Mouse" with clutch control.
C++ Flutter/Dart Win32 API Winsock2 UDP
